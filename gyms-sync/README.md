# Gyms連携（予約の自動反映）

Gyms（予約管理アプリ）から届く「予約が入りました」「予約がキャンセルされました」「予約変更されました」というメールを自動で読み取り、このアプリの予約データへ反映する仕組みです。

無料で使える「Google Apps Script」（Googleが提供する自動化ツール）を、Gymsの通知メールが届くGoogleアカウントに設定して使います。追加のサーバーや有料サービスは不要です。

## できること・できないこと

- Gymsから新しい予約通知メールが届くと、5分ごとに自動でチェックされます
- 「予約が入りました」→ このアプリに予約（予約中）を追加します
- 「予約がキャンセルされました」→ 該当する予約を削除します
- 「予約変更されました」→ 元の予約を削除し、変更後の日時で予約を追加します
- Gymsのメールに書かれている会員名が、このアプリに登録済みの会員名と一致しない場合は、自動反映せず「Gyms確認」タブに記録されます（内容を確認のうえ、手動で調整してください）
- 設定した時点より前にすでに届いているメールは対象外です（今後届く新しいメールのみ反映されます）
- 会員のコース・契約残り回数・目標値などはこの仕組みでは変更されません（予約の追加・削除のみです）

## セットアップ手順（初回のみ）

### 1. Supabase側の準備
まだの場合は、先に [`supabase/migration.sql`](../supabase/migration.sql) の内容をSupabaseのSQL Editorで実行してください（Gyms連携用のテーブルが追加されます）。

### 2. Google Apps Scriptのプロジェクトを作成する
1. Gymsの通知メールが届くGoogleアカウントで、ブラウザから https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. 左上のプロジェクト名（「無題のプロジェクト」）をクリックし、「BUG Gyms連携」など分かりやすい名前に変更する

### 3. コードを貼り付ける
1. 中央のエディタに最初から表示されている内容（`function myFunction() {}` など）をすべて削除する
2. このフォルダの [`Code.gs`](./Code.gs) の中身をすべてコピーし、エディタに貼り付ける
3. 上部の保存アイコン（またはCtrl+S / Cmd+S）で保存する

### 4. SupabaseのURLとキーを設定する
1. 左メニューの歯車アイコン「プロジェクトの設定」を開く
2. 一番下の「スクリプト プロパティ」で「スクリプト プロパティを追加」を押し、以下の2つを登録する

   | プロパティ | 値 |
   | --- | --- |
   | `SUPABASE_URL` | `supabase-config.js` に設定しているURL（例：`https://xxxxxxxxxxxx.supabase.co`） |
   | `SUPABASE_ANON_KEY` | `supabase-config.js` に設定している anon public キー |

3. 「スクリプト プロパティを保存」を押す

### 5. 自動実行を有効にする
1. エディタの画面に戻る（左メニューの「エディタ」）
2. 上部の関数選択ドロップダウンから `setupTrigger` を選ぶ
3. 「実行」ボタンを押す
4. 初回は「承認が必要です」という画面が出るので、指示に従ってGoogleアカウントでの許可（Gmailの読み取り、外部サービスへの接続）を進める
   - 「このアプリは確認されていません」という警告が出ることがありますが、自分で作成したスクリプトなので「詳細」→「（プロジェクト名）に移動」で進んで問題ありません
5. 実行が成功すると、ログに「5分ごとの自動実行トリガーを設定しました。」と表示されます

これで、5分ごとに自動でGymsからのメールをチェックし、予約データへ反映するようになります。

### 6. 動作確認をする
1. 上部の関数選択ドロップダウンから `testRunNow` を選ぶ
2. 「実行」ボタンを押す
3. 上部メニューの「表示」→「ログ」で実行結果を確認する
4. アプリの「Gyms確認」タブを開き、正しく反映されているか確認する（会員名が一致しない場合はここに一覧表示されます）

## うまく反映されない場合

- 会員名が一致しているか確認してください（全角・半角スペースの違いは自動で吸収されますが、氏名の表記そのものが違うと一致しません）
- 「Gyms確認」タブに「メール内容を解析できませんでした」と表示された場合、Gymsのメール文面が想定と異なる形式だった可能性があります。個人情報を除いたメール本文を共有していただければ、解析処理を調整します
- 実行ログ（「表示」→「ログ」）にエラーが出ていないか確認してください
